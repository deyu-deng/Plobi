## Plobi v0.2.0

[中文](#) | [English](https://github.com/deyu-deng/Plobi/releases/download/v0.2.0/Plobi-v0.2.0-release-notes.en.md)

这一版把三件一直缺着的事补上了：信源可以自己装，Agent 可以自己挑模型，日程能由 L1 排出来。

安装包在下方，Windows / macOS / Linux 三平台都有。

### 新增

- **信源可以自己接** — 设置里多了一个信源区。每条信源自带图标和首次配置表单，装上就能用；也可以装第三方信源包。设置页按你装了什么显示什么，没装的分类不画。
- **每个 Agent 可以自己挑模型** — Agent 名册每一行都能选模型，不选就跟随默认。工具配置共享一份，但每个 Agent 可以单独开关。
- **左栏只留 Agent** — 原来的分身页、命令面板入口和快捷键都撤了，左栏五种行吃同一套外观，日程只留一个入口。
- **日程能由 L1 排** — 晚上 20:00 那一轮先自己排一次明天的计划，再念给你听。计划可以用对话改（「把下午那节挪到三点」），也可以在界面上勾掉做完的那几行。
- **额度读数** — 桌面能读到每条腿现在能不能用、今天花了多少；读不到「还剩多少」就空着，不拿估算值糊弄。
- **网络出口面板** — 出站流量走哪条路在界面上可配，保存即生效。
- **计时作业能指定收件人** — 定时任务记录补上「归谁跑」，这一格缺了就不起。
- **笔记住进右栏** — 笔记从独立视图挪进已有的预览面板，可直接「加入对话」。
- **钉钉接入登记** — 钉钉作为消息类信源登记进来（收发走网关侧，采集层暂不做历史回填）。

### 改进

- **本地只起一个后端** — 多个后端进程收成一个，身份跟着请求走；用量与概览按名册同源读。
- **会话归属到 Agent** — 每条会话记着是谁的，跨 Agent 搜索不再串库。
- **额度卡片说人话** — 开机自连之后不再显示「未连接」；关掉连接是一个按钮，不是一句判词。
- **状态栏不印状态码** — 「deferred」变成「这一波还没接」，「red」变成「试过，没起来」。
- **微信日采自愈** — 采集子进程意外退出后会自己拉起来；微信那个 503 的真因（密钥走了命令行）修掉了。

### 修复

- **说一句「排一下明天」不再抹掉已排的块** — 缺动作就照实拒绝，改成纯读。
- **早报里的「明天」不许静默答成今天**。
- **名册里没有家的条目不再被当成可连的分身** — 不再无限重启，也不再把整张名册打成 500。
- **Network 面板进得去** — 导航 id 不在路由白名单里导致点不开。

### 安装

下载下方的安装包直接运行——Windows 用 `.exe` 或 `.msi`，macOS 用 `.dmg`，Linux 用 `.deb` / `.rpm` / `.AppImage`。

<details>
<summary>从源码跑</summary>

```bash
git clone https://github.com/deyu-deng/Plobi.git
cd Plobi
uv venv --python 3.13 && uv sync --extra dev --extra acp --extra messaging --extra web --extra anthropic
cd apps/desktop && npm install && npm run dev
```

</details>
