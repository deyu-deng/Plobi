## Plobi v0.2.1

[中文](https://github.com/deyu-deng/Plobi/releases/tag/v0.2.1) | [English](https://github.com/deyu-deng/Plobi/releases/download/v0.2.1/Plobi-0.2.1-release-notes.en.md)

这是一版热修复。v0.2.0 装完之后会在启动时崩，这版修掉了。

安装包在下方。

### 修复

- **启动不再崩** — 乐观占位的那条消息缺一段元数据，聊天运行时读到它就抛异常。发布构建会直接崩在首启，这版把它归一化掉了。

### 改进

- **新装的机器不再自带一堆种子文件** — 首次创建只留 sessions 与 logs，`.env` 与 `SOUL.md` 两腿摘掉了。
- **额度余额读数补齐** — 读得到就出数并带单位，读不到就返回 `None` 加上原因，不再半吊子。

### 安装

下载下方的安装包直接运行——Windows 用 `.exe` 或 `.msi`，macOS 用 `.dmg`，Linux 用 `.deb` / `.rpm` / `.AppImage`。
