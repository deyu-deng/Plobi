# Plobi v0.1.0

[中文](https://github.com/deyu-deng/Plobi/releases/tag/v0.1.0) | [English](#)

This is the first public release of Plobi. It comes from the Hermes Agent foundation, and it ships a desktop app you can install and run, plus the backend that goes with it.

Grab the installer below. A 64-bit Windows machine is all you need.

### What you get

- **Desktop console** — An Electron app. Agent roster on the left, conversation in the middle, agenda timeline and notes on the right.
- **Local AI gateway** — An OpenAI-compatible `/v1/chat/completions` endpoint on localhost that puts Cursor, Antigravity, WorkBuddy and Marvis quotas behind one door. A conversation stays pinned to the same account, and the gateway moves to the next source when one fails.
- **Quota pool** — Every source is probed and lands in one of three states: usable, degraded, or unavailable. Dispatch prefers a source that still works and switches when one errors out. When remaining balance can be read it is reported; when it cannot, the field stays empty.
- **Agenda** — Schedule changes get pulled out of chat logs and asked about before they land on the calendar. The agenda has a week view.
- **Secretary and agents** — An L1 secretary talks to you and delegates; L2 agents take on projects. Each one gets a time budget based on its own measured latency.
- **Sessions and memory** — Full-text search across sessions (FTS5), and skills that grow out of experience.
- **Butler** — Three scheduled jobs: morning report, to-do digest, quota warning.

### Install

Download the Windows installer below and run it — no prerequisites beyond a 64-bit Windows system.

<details>
<summary>Run from source</summary>

```bash
git clone https://github.com/deyu-deng/Plobi.git
cd Plobi
uv venv --python 3.13 && uv sync --extra dev --extra acp --extra messaging --extra web --extra anthropic
cd apps/desktop && npm install && npm run dev
```

</details>
