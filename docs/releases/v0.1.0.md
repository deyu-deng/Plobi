## Plobi v0.1.0

[中文](#) | [English](https://github.com/deyu-deng/Plobi/releases/download/v0.1.0/Plobi-v0.1.0-release-notes.en.md)

这是 Plobi 的第一个公开版本，来自 Hermes Agent 那套底子，带着一个能装、能跑、能聊的桌面端，以及围绕它的一整套后端。

安装包在下方，64 位 Windows 直接装即可。

### 有哪些东西

- **桌面控制台** — Electron 应用。左栏是 Agent 名册，中间是对话，右栏是日程时间线与笔记。
- **本地 AI 网关** — 本机一个 OpenAI 兼容的 `/v1/chat/completions` 端点，把 Cursor、Antigravity、WorkBuddy、Marvis 几家的额度收在一个口后面。会话粘在同一个账号上，源挂了自动换下一个。
- **额度池** — 逐个源探活，分「可用 / 降级 / 不可用」三档；派活时优先挑还能用的那个源，源报错就换一个。读得到「还剩多少」就报数，读不到就空着。
- **日程** — 从聊天记录里抽日程，落到日历前先问你一句；日程支持周视图。
- **秘书与分身** — L1 秘书跟你对话并分派，L2 分身按项目承接；派活时按各分身自己的耗时给预算。
- **会话与记忆** — 会话全文检索（FTS5），技能可以从经验里长出来。
- **管家** — 早报、待办摘要、额度告警三个定时任务。

### 安装

下载下方的 Windows 安装包直接运行——除了 64 位 Windows，不需要别的前置条件。

<details>
<summary>从源码跑</summary>

```bash
git clone https://github.com/deyu-deng/Plobi.git
cd Plobi
uv venv --python 3.13 && uv sync --extra dev --extra acp --extra messaging --extra web --extra anthropic
cd apps/desktop && npm install && npm run dev
```

</details>
