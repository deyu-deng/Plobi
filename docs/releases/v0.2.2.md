## Plobi v0.2.2

[中文](#) | [English](https://github.com/deyu-deng/Plobi/releases/download/v0.2.2/Plobi-v0.2.2-release-notes.en.md)

这一版专门修装机：装完之后那些红灯、那些点了必然失败的行、以及排重排错的日程。

安装包在下方。

### 修复

- **装完 aigw 不再一片红灯** — 装机批量修复的第一件事。
- **左栏不再有「点了必然失败」的行** — 装不好的条目不该出现在列表里。
- **同一节课不会被排两遍** — 排程以前只看提案内部，看不见当天已经有的那一件，现在会去重。
- **限速没到就一个字都不碰** — 对账落成一条命令，该提交的时候才提交。
- **采集的时间列归位** — 「这条消息自己的时间」不再读成别的；会话与可见性两列按真实口径取值。
- **新家不再播种那份会话种子** — 创建侧只剩 sessions 与 logs。

### 新增

- **记忆收成两枚动作** — `memory_read(scope)` 与 `memory_write(scope, parts, source)`，所有角色都能用同一套。
- **L0 记忆那一半打开** — 真源翻成开，挤出去的条目真的进待确认层。
- **定时作业能指定收件人** — 建作业那张嘴补上了入口。

### 安装

下载下方的安装包直接运行——Windows 用 `.exe` 或 `.msi`，macOS 用 `.dmg`，Linux 用 `.deb` / `.rpm` / `.AppImage`。
