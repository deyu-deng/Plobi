## Plobi v0.3.3

[中文](https://github.com/deyu-deng/Plobi/releases/tag/v0.3.3) | [English](https://github.com/deyu-deng/Plobi/releases/download/v0.3.3/Plobi-0.3.3-release-notes.en.md)

v0.3.3 把首装那十步重做成一套玻璃卡，选中一段文字即可直接交给智能体改写；记忆与档案那一屏收成一份一行，采集腿的身份与真名逐条补齐，发版这一环也装上了硬闸。

安装包见本页面下方资产。

### 新增

- **首装引导重做** — 首装那十步换成玻璃磨砂卡；账号、密钥、订阅额度三张卡各自接上自己的配置流程，展开后为一屏可滚动的列表；末步落两份文件，写入画像与性情。
- **选中后直接操作** — 在对话里或侧边栏的文件里选中一段文字，该处出现一排按钮：复制、引用、发给别的智能体、让智能体改写这一段。发给别的智能体时直接切换至该智能体，并把它要处理的文字放入输入框。
- **引用与附件成为正文中的一枚 chip** — 引用与附件不再是那条不可移除的灰色条，鼠标悬停即出预览。
- **长文阅读全文** — 长文的悬停提示不再被截断，改为可滚动、可选择的浮层。
- **记忆按条目修改** — 记忆库支持只修改指定的条目，其余字节不变。
- **文档预览记住阅读位置** — 关掉再打开同一份文档，回到上次看到的位置；Word、表格、幻灯片、PDF 各按文件分别记住，窗口宽度变了也各自归位（此前为每次都从第一页重新看）。

### 改进

- **档案卡** — 对话卡右上角的一族入口收进同一个容器；去边框、逐段可折叠、浮层可拖动；窗口变窄时自动折叠，只保留图标。
- **记忆屏** — 一份一行、条目进入抽屉；四个分区名跟随界面语言；近况一栏改为各首席的近况摘要。
- **外部工具的软件名** — 配置项改为软件名，网关的机器标识不再显示；旧标识在读取时仍然识别。
- **外脑定名** — 对外称 Exocortex／外脑，代码标识符沿用原名。
- **称谓收尾** — 指挥与首席不再使用旧代号，文件名与内部标识一并更换。
- **采集腿各自管理进程** — 每条采集腿在采集那一轮自行启动与回收，不保留常驻进程；检测到已在运行的那一份时只复用，不做处置。
- **微信与钉钉的身份** — 发言人、真名、是否为账号本人、群聊与分组、非文本消息与真实文件字节，逐条补齐。
- **写入与触发各收一处** — 采集的写库与触发各只有一个入口，新增采集腿不再需要参照既有实现推断。
- **发版硬闸** — 版本号一处真源、双语说明齐、三平台资产齐，缺一不发；发布页的写法另有一道审查，措辞与「写给谁看」分开管。

### 修复

- **Windows 安装程序在脚本解析处失败** — 含中文的脚本补上 UTF-8 标记，安装不再停在那道解析错误上（此前为安装中断）。
- **引擎启动时出现黑色窗口** — 窗口抑制归入一个模块，不再闪出控制台窗口（此前为闪窗一闪）。
- **脑内缺少门禁时无法创建项目分身** — 放行，只创建档案与记忆文件，脑内字节不变（此前为创建失败）。
- **备份遗漏官方记忆** — 外部记忆服务不再兼管官方脑之后，备份自行向脑获取根路径（此前为备份不全）。
- **记忆提醒被关闭** — 提醒不再被误关闭，硬编码契约置于身份块最前（此前为提醒静默失效）。
- **模型路由** — 只识别两个角色，退休档位既不读取也不写回（此前为仍按旧档位路由）。
- **日志重复** — 同一句话不再写入两遍（此前为日志出现重复行）。

### 安装

下载下方的安装包直接运行——Windows 用 `.exe`（可选择数据目录）或 `.msi`（使用默认位置），macOS 用 `.dmg`，Linux 用 `.deb` / `.rpm` / `.AppImage`。
