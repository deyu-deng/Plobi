## Plobi v0.2.1

[中文](https://github.com/deyu-deng/Plobi/releases/tag/v0.2.1) | [English](https://github.com/deyu-deng/Plobi/releases/download/v0.2.1/Plobi-0.2.1-release-notes.en.md)

v0.2.1 修复 v0.2.0 安装后聊天页崩溃的问题，并调整初始文件与额度读数。

安装包见本页面下方资产。

### 修复

- **聊天页崩溃** — v0.2.0 安装后，在存在进行中会话时，聊天页会因占位消息缺少元数据而渲染报错。本版为占位消息补齐完整元数据，并按会话固定消息 id。

### 改进

- **停止播种初始文件** — 新建分身家只创建 `sessions/` 与 `logs/`，不再复制 `.env` 与 `SOUL.md`。主目录与已存在的家不受影响。
- **额度余额读数** — 余额可读取时返回数值与单位（美元、积分或请求数），不可读取时返回 `None` 并附具体原因。

### 安装

下载下方的安装包并运行——Windows 用 `.exe` 或 `.msi`，macOS 用 `.dmg`，Linux 用 `.deb` / `.rpm` / `.AppImage`。
