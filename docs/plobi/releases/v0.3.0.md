## Plobi v0.3.0

[中文](https://github.com/deyu-deng/Plobi/releases/tag/v0.3.0) | [English](https://github.com/deyu-deng/Plobi/releases/download/v0.3.0/Plobi-0.3.0-release-notes.en.md)

这一版给桌面壳添了三块地方：知识库、日记、工作台。另外，能点一下就把整个应用升上去，也能把活交给外面的 AI 软件。

安装包在下方。

### 新增

- **左栏多了一个「知识库」** — 笔记能搜、能看大纲、能直接改；`[[双链]]` 点得开，鼠标悬停能预览。
- **多了一个「日记」** — 按天写、按天翻；随手记一句，当场就进当天那篇。
- **右栏变成一排页签** — 日程、工作区文件、档案、审阅、内置浏览器、终端都在里面，开网页不用切出去。
- **Word、Excel、PPT 能在里面直接改** — PDF 能高亮、能写批注，批注还写回文件。
- **写进记忆前先问你一句** — 该进脑的条目先落成待办，你逐条点头或驳回；设置里也能看，也能忘掉。
- **能把活交给外面的 AI 软件** — Claude Code、Codex、Gemini CLI、Qoder、Cline、OpenCode、Antigravity、腾讯 coding agent。每家装没装、登没登、能不能接着聊，都摆在那儿；它们的会话能读，话说回去也行。
- **四类专家角色可以派出** — 文件、浏览器、软件、电脑；左栏看得到它们各自的日志。
- **日程能挂清单和附件** — 也能从新来源收：邮箱（QQ、163、Gmail、Outlook、自建 IMAP）、幕布、钉钉、本科教务、课表。
- **桌面端能一键升级** — 新版来了自己会提示；点一下就下载、装好、把后端带到同一个版本号、重启。

### 改进

- **版本号不再串台** — 上面一行是这个程序的号，下面一行是后端的号。
- **装完就是完整一版** — 后端跟着安装包一起来：不用另外下载，也不用联网等它把依赖装完；装完前后端是同一个版本号。
- **「分身」这个说法取消了** — Agent 就是名册里的一行；左栏、设置页、命令行都只叫 Agent。
- **权限有三档** — 每次问、自动批准、完全访问，在输入框旁边切。
- **状态词都带下一步** — 没装、没登录、没配路径、文件不在、服务没在听，各有一句人话告诉你该怎么办。
- **主界面能切成卡片式** — 对话与工作面两张白卡能拖着换位，也能只留一面。
- **额度按家列成卡片** — 装在本机的各家各一张，给登录状态；接了 Claude Code、Codex、OpenCode、Gemini、Kiro、Cline、Antigravity、Qoder、Cursor。
- **采集频率改成一颗旋钮** — 聊天信源还能逐扇「不采」。

### 修复

- **首启不再进那个几十分钟的重装循环** — 探测超时以前被当成「环境坏了」，现在只是慢。
- **托管安装能更新了** — 「落后」以前被误判成「本地有分叉」，于是每一个托管安装都更新不了。
- **查更新没查成不再谎称「你已是最新版本」** — 被限流或者请求坏掉时说实话。
- **新版提醒要你亲手关掉那一声** — 没看见的话，下次开机还会提醒。
- **钉钉采集取的是最新那批** — 以前每轮都交同一批最旧的消息，新消息进不来。
- **Word 文档里的图片能显示了** — 解析前把非标准前缀改回常规写法。

### 安装

下载下方的安装包直接运行——Windows 用 `.exe` 或 `.msi`，macOS 用 `.dmg`，Linux 用 `.deb` / `.rpm` / `.AppImage`。
