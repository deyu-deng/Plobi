## Plobi v0.3.0

[中文](https://github.com/deyu-deng/Plobi/releases/tag/v0.3.0) | [English](https://github.com/deyu-deng/Plobi/releases/download/v0.3.0/Plobi-0.3.0-release-notes.en.md)

v0.3.0 为桌面端新增知识库、日记与工作台三块界面，并加入客户端自我更新与外部 AI 工具接入。

安装包见本页面下方资产。

### 新增

- **知识库** — 左栏新增知识库入口。笔记支持检索、大纲与就地编辑；`[[双链]]` 可点击打开，悬停即预览对应笔记。
- **日记** — 左栏新增日记入口。按日撰写、按日翻阅，写入的内容即时归入当日条目。
- **工作台页签** — 右栏改为页签组，容纳日程、工作区文件、档案、审阅、内置浏览器与终端。
- **Office 文档就地编辑** — Word、Excel、PowerPoint 支持在应用内直接编辑。
- **PDF 批注** — 支持高亮与批注，批注内容回写原文件。
- **记忆确认层** — 记忆写入先落为待确认条目，逐条批准或驳回；设置页提供同一列表与遗忘入口。
- **外部 AI 工具** — 接入 Claude Code、Codex、Gemini CLI、Qoder、Cline、OpenCode、Antigravity 与腾讯 coding agent。每项展示安装状态、登录状态与会话续接能力，其会话可读取与回复。
- **专家角色** — 新增文件、浏览器、软件、电脑四类角色，可派发任务；左栏显示各角色的执行日志。
- **日程清单与附件** — 日程条目支持附加清单与附件。
- **新信源** — 邮箱（QQ、163、Gmail、Outlook、自建 IMAP）、幕布、钉钉、本科教务与课表。
- **客户端更新** — 桌面端可在提示后完成下载、安装、后端版本同步与重启。

### 改进

- **版本号分行** — 首行显示桌面端版本，次行显示后端版本，两者不再共用同一个数字。
- **后端随安装包分发** — 安装过程不再另行下载依赖，安装完成后前后端版本号一致。
- **Agent 统一称谓** — 「分身」从产品中移除；左栏、设置页与命令行统一使用 Agent。
- **权限三档** — 每次询问、自动批准与完全访问，切换入口位于输入框旁。
- **状态提示附处置建议** — 未安装、未登录、未配置路径、文件缺失、服务未监听各给出对应说明。
- **卡片式布局** — 对话与工作面显示为两张可拖动换位的卡片，也可单面显示。
- **配额按厂商列出** — Claude Code、Codex、OpenCode、Gemini、Kiro、Cline、Antigravity、Qoder 与 Cursor 各一张卡片，显示登录状态。
- **采集频率控件** — 采集频率改为旋钮；聊天信源可逐项停用。

### 修复

- **首启重装循环** — 探测超时此前被判定为环境故障，现按响应缓慢处理，首启不再进入重装循环。
- **托管安装无法更新** — 浅克隆状态此前被判为本地分叉，导致托管安装无法更新；现已恢复更新能力。
- **更新检查失败时的结论** — 限流或响应异常时不再显示「已是最新版本」，改为报告失败原因。
- **新版本提示** — 提示在手动关闭前持续显示；未确认的提示在下一次启动时再次出现。
- **钉钉采集取数** — 此前每轮返回同一批最旧消息，新消息无法进入；现改为取最新一批。
- **Word 文档图片** — 解析前将非标准前缀改写为标准形式，文档内图片正常显示。

### 安装

下载下方的安装包直接运行——Windows 用 `.exe` 或 `.msi`，macOS 用 `.dmg`，Linux 用 `.deb` / `.rpm` / `.AppImage`。
