## Plobi v0.2.2

[中文](https://github.com/deyu-deng/Plobi/releases/tag/v0.2.2) | [English](https://github.com/deyu-deng/Plobi/releases/download/v0.2.2/Plobi-0.2.2-release-notes.en.md)

v0.2.2 处理安装与日常使用中的若干问题：本地额度网关起不来、点击必然失败的条目、重复排入的日程，以及采集侧两列取值失真。

安装包见本页面下方资产。

### 修复

- **本地额度网关启动** — 依赖闭包补上 `h2`，网关可正常启动；缺少 `h2` 时降级到 HTTP/1.1。网关的报错同时写入 `desktop.log`，不再只剩一个没有原因的超时。
- **名册条目的可用性** — 点击必然失败的条目改为禁用并写明原因，避免用户点进去却失败。
- **课表去重** — 排程会比对当天已存在的条目：提案阶段被打回，落库前再摘一次，判据为同时段同题。
- **只读对账命令** — 新增一支对账命令。限速间隔未到时连学校都不碰，只报告还需多久；也可只看库内一侧与上一轮的实际请求记录。
- **信息池的会话与可见性两列** — 信息池本体入仓，这两列实际存储，读取时可按其筛选。采集侧给出取值口径，即窗口用户名与是否群聊；时间字段的形状与语义由一支核对命令钉住。本版微信管线尚未向信息池写入。

### 新增

- **记忆读写两枚动作** — `memory_read(scope)` 与 `memory_write(scope, parts, source)`，默认对所有角色可用。
- **L0 记忆层** — 出厂即开启。一格挤到压线时，被挤出的条目进入待确认层，不静默丢弃。
- **定时作业收件人** — 建作业与改作业都可指定名册中的 Agent 名字；不填则归当前说话的那一位，再取不到会在结果里说明。

### 安装

下载下方的安装包并运行——Windows 用 `.exe` 或 `.msi`，macOS 用 `.dmg`，Linux 用 `.deb` / `.rpm` / `.AppImage`。
