## Plobi v0.3.2

[中文](https://github.com/deyu-deng/Plobi/releases/tag/v0.3.2) | [English](https://github.com/deyu-deng/Plobi/releases/download/v0.3.2/Plobi-0.3.2-release-notes.en.md)

v0.3.2 为桌面端加入派活与授权：对话里说定一件事即成授权，派出去的工作有单据可查、可叫停、能到点汇报；外部工具的清单、账号与接入引导一并归位。

安装包见本页面下方资产。

### 新增

- **对话里的授权** — 在对话里说定一件事即成授权，那句话本身留作凭据；授权记在账本里，可查可撤。通过、驳回与撤回都是明面上的决定，Agent 起草的草稿不生效，人点头才算。
- **派活的单据** — 派出去的工作有单据可查：当前状态、派给了谁、属于哪个域；「撤销」即可叫停。
- **定时作业主动汇报** — 定时作业到点后主动汇报它的结论；出厂一律先问。
- **外部工具清单** — 50 家外部工具归到一张表，各占一行；新增一家只改一处。
- **外部工具的账号与腿** — 一族下面有哪几个账号、派活用哪一个；一家的腿可以有多条，派活时能点名走哪一条。
- **未装工具的接入引导** — 48 家带安装引导；未装的那几家第一次接入时给出下载与登录步骤。
- **更多外部工具的会话续接** — Gemini CLI、Kilo Code、Cline、kiro、GitHub Copilot 与 Qoder 中国版的会话可读取与回复。
- **笔记、日记与档案的细动作** — 笔记、日记、档案三类补上细动作：列全库、看链接、改属性、勾一条、改一个阶段。
- **信源管理** — 信源可查看、读取、翻开关、改采集频率、写配置，也能直接触发一轮采集。
- **Agent 能力可问可配** — 一处能问「这个 Agent 现在能调什么」；名手自带的工具箱与黑名单可在配置面里改。

### 改进

- **角色称谓** — 四语界面里最高一层称「指挥」，第二层称「首席」，其余两类角色称「名手」与「客席」；旧称谓不再上屏。
- **界面不再反复重建** — 整条对话转录不再每 2.5 秒被拆掉重挂；笔记页滚动时 Markdown 不再整树重建。
- **加载态** — 统一成品牌小乌龟沿进度条左→右行走；切换界面时加载画面单独显示。
- **档案卡随容器收窄折叠** — 对话卡右上角那一列，档案与待放行共用一套壳；窄了就折叠，只留图标。
- **浏览器工具收成一把** — 十几把点击类工具合并成一条，Agent 调用时不再逐个列举。
- **模型名上屏** — 屏上的模型名不再带服务商前缀，直接显示模型本身的名字。
- **首席调用客席的默认家** — 默认改成「本机真正可用的那一家」。
- **左栏外部会话的标题** — 厂商自起的名字优先，取不到才剥掉包裹取人话。
- **换运行时后转录跟随** — 同一场对话换运行时绑定，屏上那份转录跟着走。

### 修复

- **随包后端能真正拉起** — 装完随包的后端此前起不来，现已能正常启动。
- **首次启动与更新** — 首启标记能自愈；托管安装遇到浅历史先补全，更新按安装方式分别处理。
- **关于页只印一个版本号** — 此前印着好几个版本号，现在永远只印一个。
- **应用图标** — 三个平台各一张对味的图标；菜单栏图标改用可随系统外观变色的样式。
- **额度工具** — 那条腿统一叫 WorkBuddy，不再自称 CodeBuddy；它的自更新下载可断点续传，停滞会被判定并重试三轮。
- **微信信源未开时误报采集故障** — 未开启时不再报「采集故障」。
- **引擎设置** — 引擎未开时「系统代理接管」那一格置灰；保存后引擎那一节不再丢失。
- **被本地闸拒掉的消息** — 拒绝带上理由，被拒的那条进队列。
- **发送按 Agent 分桶** — 每个 Agent 各有自己的忙闲状态、队列与发送锁，互不占用。
- **笔记、日记与档案的位置** — 三类内容不再多套一层目录，直接落在数据目录下。

### 安装

下载下方的安装包直接运行——Windows 用 `.exe`（可选择数据目录）或 `.msi`（使用默认位置），macOS 用 `.dmg`，Linux 用 `.deb` / `.rpm` / `.AppImage`。
