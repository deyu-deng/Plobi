## Plobi v0.3.2

[中文](https://github.com/deyu-deng/Plobi/releases/tag/v0.3.2) | [English](https://github.com/deyu-deng/Plobi/releases/download/v0.3.2/Plobi-0.3.2-release-notes.en.md)

上一版：[v0.3.1](https://github.com/deyu-deng/Plobi/releases/tag/v0.3.1)

相对 v0.3.1，这一版把派活与授权做成直接可用的能力：对话里说定一件事即成授权，授权可查可撤；派出去的工作有单据可查、可叫停、能到点汇报。外部工具归到一张真源表，新增一家只改一处。界面这头收掉了三处卡顿与重挂：整条对话转录不再每 2.5 秒被拆掉重挂，笔记页滚动不再整树重建，加载态统一成品牌小乌龟沿进度条行走。

安装包见本页面下方资产。

### 新增

- **对话里的授权** — 在对话里说定一件事即成授权，那句话本身留作凭据；这类授权记在账本里，可查、可撤回。
- **授权的三种决定** — 通过、驳回、撤回。Agent 起草的草稿不生效，人点头才算。
- **任务单据** — 派出去的工作有单据可查：当前状态、派给了谁、属于哪个域；点「撤销」即可叫停。
- **到点主动汇报** — 定时作业到点后主动汇报判据；出厂一律先问。
- **外部工具真源表** — 外部厂商归到一张表，50 家各占一行，新增一家只改一处；四张出口表（契约、安装引导、会话、账号）全部由它派生。
- **外部工具的账号与腿** — 一族下面有哪几个身份、派活用哪一个；一家的腿可以有多条，派活时能点名走哪一条。
- **未装工具的接入引导** — 48 家带安装引导；未装的那几家第一次接入时给出下载与登录步骤。
- **更多外部工具的会话续接** — Gemini CLI、Kilo Code、Cline、kiro、GitHub Copilot、Qoder 中国版的会话可读取与回复。
- **人读面的动作级工具** — 笔记、日记、档案三类补上细动作：列全库、看链接、改属性、勾一条、改一个阶段。
- **信源管理的六把动作** — `source_list`、`source_read`、`source_enable`、`source_set_cadence`、`source_configure`、`source_collect`：看见、读、翻开关、改频率、落配置、自己触发一轮采集。
- **Agent 能力可问可配** — 一处能问「这个 Agent 现在能调什么」；名手自带的工具箱与黑名单可在配置面里改。

### 改进

- **界面称谓统一** — 四语界面里 L1 称「指挥」、L2 称「首席」，其余两类角色称「名手」与「客席」；旧称谓不再上屏。
- **对话转录不再周期性重挂** — 消息组件的身份按内容进依赖，整条转录不再每 2.5 秒被拆掉重挂。
- **加载态** — 统一成品牌小乌龟沿进度条左→右行走；切换界面时加载画面单独显示。
- **笔记页滚动** — 滚动走 rAF 二分查表，Markdown 不再整树重建。
- **档案卡随容器收窄折叠** — 对话卡右上角那一列，档案与待放行共用一套壳；窄了就折叠，只留图标。
- **浏览器工具收成一把** — 十几把点击类工具停止注册，门类收成 `browser_exec`。
- **网关目录改名** — `quota_hub` 改成 `bezel`；模型名上屏去掉上游前缀。
- **首席调用客席的默认家** — 默认改成「本机真正可用的那一家」。
- **左栏外部会话的标题** — 厂商自起名的名字优先，取不到才剥掉包裹取人话。
- **换运行时后转录跟随** — 同一场对话换运行时绑定，屏上那份转录跟着走。

### 修复

- **随包后端叫不起来** — 随包后端此前是死代码：判定缺失、构建缺包与下载多源回退三处一并修好，装完的后端能被真正拉起。
- **首启标记** — bootstrap marker 自愈，更新按安装方式分流。
- **浅克隆装机** — clone 按 ref 分档，浅历史先补全。
- **关于页只印一个版本号** — 此前印着好几个版本号，现在永远只印一个。
- **图标** — 三个平台各一张对味的图标，菜单栏改用 template image。
- **额度腿改名** — 那条腿统一叫 WorkBuddy，不再自称 CodeBuddy。
- **额度自更新下载** — 断点续传、停滞判定与三轮重试。
- **微信信源未开时误报采集故障** — 未开启时不再报「采集故障」。
- **引擎关着时「系统代理接管」仍可点** — 引擎未开时那一格置灰。
- **保存抹掉 engine 段** — 保存后 engine 段不再丢失。
- **被本地闸拒掉的消息静默消失** — 拒绝带上理由，被拒的那条进队列。
- **发送按 Agent 分桶** — 忙时语义、队列桶与发送锁都归到一个 Agent。
- **人读面的落点** — 人读面从 `plobi/mind/` 移到 `plobi/human/`，且不再套一层目录。

### 安装

下载下方的安装包直接运行——Windows 用 `.exe`（可选择数据目录）或 `.msi`（使用默认位置），macOS 用 `.dmg`，Linux 用 `.deb` / `.rpm` / `.AppImage`。
