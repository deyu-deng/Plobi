## Plobi v0.3.1

[中文](https://github.com/deyu-deng/Plobi/releases/tag/v0.3.1) | [English](https://github.com/deyu-deng/Plobi/releases/download/v0.3.1/Plobi-0.3.1-release-notes.en.md)

v0.3.1 为桌面端加入统一维护的订阅额度，补齐笔记右栏与二级 Agent 会话续接，并可按 Agent 单独指定模型。

安装包见本页面下方资产。

### 新增

- **订阅额度统一维护** — 各家服务的登录、模型目录与额度查询统一由 magpie 提供；它随安装包装上并在启动时运行，登录入口与各家名册一并到货。
- **卡片清单跟随名册** — magpie 增减或改名一家厂商，Plobi 侧只改一张映射表：是否出卡、卡片名称与登录方式由这张表决定，已发布的模型 id 与预设保持不变。
- **本机额度配置导入** — 设置页与引导页列出本机已有的额度配置，由用户决定是否导入；导入写副本，原工具保持登录。
- **二级 Agent 会话续接** — 进入二级 Agent 时沿用它自己的会话，上一轮说过的内容保留。
- **按 Agent 指定模型** — Models 页可为单个 Agent 指定模型，选择写进该 Agent 自己的条目。
- **笔记右栏** — 上一版笔记没有右栏；这一版补齐反向链接、出链、标签、属性与书签五块。

### 改进

- **额度层可单独升级** — 订阅额度这一层可以单独更新，不必等整个应用更新；随包那份作为下限。
- **登录入口随包到货** — 各家的登录项与名册随安装包一起装上，新装的机器上登录入口按名册列出，不再是空白。
- **使用情况默认不上报** — magpie 每日会发一次使用情况；这一版起该项上报默认关闭。

### 修复

- **模型在选择框中切不动** — 在模型选择框里切换模型一律报「Unknown provider」；现可正常切换。
- **点 `+` 发起的登录没有反应** — 登录需要终端执行，界面未挂载时停在空白页；现由终端执行登录命令、浏览器自动打开，界面异常时自动重载。
- **订阅额度整屏停在加载中** — 该屏取数排在别屏之后，凭据校验超时后整屏只剩一个转圈；现两屏互不阻塞。
- **卡片图标退回首字母** — 22 张卡里只剩三张带图标；现按新名册补齐：12 家用品牌色字形，5 枚官方标志，其余 3 家保留首字母。
- **免费池显示为已配置** — OpenCode 免费池在没有密钥时仍显示可用；现只认付费密钥，无密钥时标注凭据缺失。
- **无法启动的 Marvis 卡上屏** — 这两张卡在本机均无法启动；现移出卡片清单，配置中对应的项默认关闭。
- **旧版本副本残留** — 每更换一次额度层版本就在磁盘留一份旧副本（每份约 74 MB）；现替换后清除。
- **下载物混在配置目录里** — 额度层的下载文件放在配置目录内，备份或迁移配置时会被一并带走；现移出配置目录。
- **升级后额度层接管** — 客户端升级后，已有的副本可能被旧版本占位；现正确接管，随包版本更高时不再被旧版本顶住。
- **卸载保留数据目录记录** — 上一版卸载会删掉数据目录的路径记录，重装后回到系统盘默认位置；这一版卸载保留该记录。
- **数据目录不可用时启动失败** — 数据目录位于移动硬盘或副盘、该盘没挂载时，启动会以路径不存在而终止；现退到下一档可用目录继续启动，并在启动日志中注明落点与原因。
- **自更新重复下载安装包** — 每次更新都从头下载约 400 MB；现已完成下载的包直接复用，中途中断的按已有字节续传，收尾核对官方尺寸，尺寸不符的包不交付安装器。
- **全角字符命名的 Agent 查找失败** — 查找只对名册一侧做归一化，查询串保持原样，含全角罗马数字等字符的名称无法命中；现两侧使用同一套归一化。
- **Agent 的身份与描述** — 身份与描述原先取自每个 Agent 各自的目录，该目录已停用；现统一读取名册中的条目。

### 安装

下载下方的安装包直接运行——Windows 用 `.exe`（可选择数据目录）或 `.msi`（使用默认位置），macOS 用 `.dmg`，Linux 用 `.deb` / `.rpm` / `.AppImage`。
