## Plobi v0.3.1

[中文](https://github.com/deyu-deng/Plobi/releases/tag/v0.3.1) | [English](https://github.com/deyu-deng/Plobi/releases/download/v0.3.1/Plobi-0.3.1-release-notes.en.md)

v0.3.1 把额度适配器从客户端中拆出单独分发，补齐笔记右栏与按 Agent 指定模型，并修掉上一版在数据目录、自更新与身份查找上的若干故障。

安装包见本页面下方资产。

### 新增

- **额度适配器独立分发** — magpie 不再随客户端一同发布。适配器自行检查新版本、下载并校验后替换；替换后无法启动时回退到随包的那一份。入口在状态栏的额度菜单，未启用时不产生下载。
- **本机账号配置导入** — 向导与设置页可查看本机已有工具的登录态，并选择是否导入。导入写入的是副本，原工具保持登录。
- **二级 Agent 会话续接** — 进入二级 Agent 时沿用其自身会话；此前每次都新建一条，上一轮内容不保留。
- **按 Agent 指定模型** — Models 页可为单个 Agent 指定模型，选择写入该 Agent 在名册中的条目，不再全机共用一档。
- **笔记右栏** — 补齐反向链接、出链、标签、属性与书签五块。

### 改进

- **本机打包携带离线依赖** — 本机打出的安装包此前在首启时仍要从 PyPI 解析依赖；现在随包携带离线依赖，首启无需联网。
- **打包前准备工具链** — Git、Node、Python、uv、ffmpeg 与 ripgrep 在打包前备齐，已下载的部分直接复用，网络抖动不再导致构建等待或重复下载。
- **打包前剔除构建垃圾** — `dist` 的旧哈希、`__pycache__`、`.map` 等在打包前移除；新增 `npm run check:payload` 校验包体，超出预算的项逐项列出。

### 修复

- **卸载保留数据目录记录** — 此前卸载会删除数据目录的路径记录，重装后回到系统盘默认位置，位于其他分区的数据看似丢失。现在卸载保留该记录。
- **数据目录不可用时启动失败** — 数据目录位于移动硬盘或副盘、该盘未挂载时，此前以不存在的路径创建目录并以 `ENOENT` 终止启动。现在退到下一档可用目录继续启动，并在启动日志中注明落点与原因。
- **自更新重复下载安装包** — 此前每次更新从头下载约 400 MB。现在已下载完成的包直接复用，中途中断的按已有字节续传，收尾核对官方尺寸，尺寸不符的包不交付安装器。
- **全角字符命名的 Agent 查找失败** — 身份查找仅对名册一侧做归一化，查询串保持原样，含全角罗马数字等字符的名称无法命中。现在两侧使用同一套归一化。
- **适配器旧版本残留** — 此前每更换一次适配器版本就在磁盘保留一份旧副本，单份约 74 MB。现在替换后清除旧版本。
- **适配器下载物位置** — 适配器下载的文件移出配置目录，备份或迁移配置时不再将其一并带走。
- **升级后适配器接管** — 客户端升级时正确接管已有的适配器，随包版本高于已下载版本时不再被旧版本占位。
- **身份数据来源** — 身份、描述与行级过滤不再依赖按 Agent 划分的家目录，统一读取名册中的条目。

### 安装

下载下方的安装包直接运行——Windows 用 `.exe`（可选择数据目录）或 `.msi`（使用默认位置），macOS 用 `.dmg`，Linux 用 `.deb` / `.rpm` / `.AppImage`。
