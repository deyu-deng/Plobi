## Plobi v0.2.0

[中文](https://github.com/deyu-deng/Plobi/releases/tag/v0.2.0) | [English](https://github.com/deyu-deng/Plobi/releases/download/v0.2.0/Plobi-0.2.0-release-notes.en.md)

v0.2.0 补齐三项能力：信源可自行安装、每个 Agent 可单独开关工具、日程可由 L1 秘书排定。

安装包见本页面下方资产，提供 Windows、macOS 与 Linux 三个平台。

### 新增

- **信源区** — 设置新增信源区。每条信源自带图标与首次配置表单，第三方信源包可直接安装；未安装的分类不显示。
- **每个 Agent 单独开关工具** — 右栏可为每个 Agent 单独关掉技能、工具集与 MCP，底层是共享的一份全局表。Agent 名册的行已支持逐行指定模型，界面上的模型下拉尚未上线。
- **左栏仅保留 Agent** — profile（分身）管理页、命令面板里的 profile 项与 profile 快捷键均已移除。左栏各类行采用统一外观，日程保留单一入口。
- **L1 排程** — 每日 20:00 的运行先排定次日计划，再行播报，写入的作业提示词自后端首次启动起生效。计划可通过对话调整，界面上可勾选已完成的条目。
- **额度只读口** — 可读出每条来源当前是否可用与当日用量。剩余额度读不到时留空并注明原因，不拿估算值充数；桌面上目前只显示是否可用。
- **网络出口面板** — 出站流量经过的出口可在界面配置，保存后立即生效。保存是整段替换，面板删掉的规则会真的消失。
- **定时任务收件人** — 定时任务记录补上执行方字段，该字段缺失或指向名册之外的 Agent 时，任务不启动。
- **笔记并入右栏** — 笔记从独立视图迁入既有的预览面板，可将选中内容加入对话。
- **钉钉接入登记** — 钉钉登记为消息类信源，收发经由网关；采集层尚未实现，界面上标记为「未在采集」。

### 改进

- **单一本地后端** — 多个后端进程合并为一个，身份随请求传递。用量与概览与名册同源读取；远程 profile 仍各自运行独立后端。
- **会话归属** — 每条会话记录其所属 Agent，跨 Agent 搜索不再混用数据。
- **额度卡片状态** — 开机自动连接后不再显示「未连接」，断开连接以按钮呈现。取消连接不等于登出该软件自身的账号。
- **状态栏文案** — 状态栏不再输出内部状态码。
- **微信日采自愈** — 采集子进程意外退出后可自行重启。微信采集返回 503 的根因已修复：密钥曾以命令行参数传递，可被本机的进程列表读到，现改为写入配置文件。

### 修复

- **排程不覆盖既有日程** — 缺少动作时直接拒绝，并将该调用改为只读。
- **早报日期口径** — 早报中的「明天」不再被静默解析为今天。
- **名册条目可连性** — 名册中缺少归属的条目不再被当作可连接的分身，不再无限重启，也不再导致整张名册返回 500。课程这类数据条目在名册里仍可见，但不再视为可运行的分身。
- **Network 面板入口** — 该面板的导航 id 不在路由白名单内，面板无法打开。

### 安装

下载下方的安装包并运行——Windows 用 `.exe` 或 `.msi`，macOS 用 `.dmg`，Linux 用 `.deb` / `.rpm` / `.AppImage`。

<details>
<summary>从源码运行</summary>

```bash
git clone https://github.com/deyu-deng/Plobi.git
cd Plobi
uv venv --python 3.13 && uv sync --extra dev --extra acp --extra messaging --extra web --extra anthropic
cd apps/desktop && npm install && npm run dev
```

</details>
