## Plobi v0.1.0

[中文](https://github.com/deyu-deng/Plobi/releases/tag/v0.1.0) | [English](https://github.com/deyu-deng/Plobi/releases/download/v0.1.0/Plobi-0.1.0-release-notes.en.md)

v0.1.0 是 Plobi 的首个公开版本，基于 Hermes Agent 的代码底座，提供可安装、可运行的桌面端及其配套后端。

安装包见本页面下方资产，仅提供 64 位 Windows 版本。

### 新增

- **桌面控制台** — Electron 应用。左栏为智能体名册，中部为对话，右栏为日程时间线，即总秘书视图下的当日视图。
- **本地 AI 网关** — 本机提供 OpenAI 兼容的 `/v1/chat/completions` 端点，为 Cursor、Antigravity、WorkBuddy、Marvis 提供统一适配。会话按 `x-session-id` 固定在同一账号，来源报错时自动切换到下一个。
- **额度池** — 后端逐来源探测健康度，分为可用、降级、不可用三档。派活时优先选择健康来源，来源报错即标记失败并改用其他来源。可读取的余额返回读数，不可读取时该字段留空。
- **日程** — 从聊天记录中提取日程，先进入待确认，确认后才写入日历。日程以列表板与当日时间轴呈现。
- **秘书与分身** — 总秘书处理对话并分派，L2 分身按项目常驻承接。日程规划器按每个分身自己设定的每周节奏折算当日时间预算。
- **会话与记忆** — 会话支持 FTS5 全文检索，含中文子串匹配。`/learn` 与后台复盘把验证过的做法固化为可复用技能。
- **管家** — 五项定时任务：早报 07:30、消息待办 12:00、额度预警 08:00、晚间规划 20:00、每日打卡 21:30。

### 安装

下载下方的 Windows 安装包并运行。除 64 位 Windows 外，无其他前置条件。

<details>
<summary>从源码运行</summary>

```bash
git clone https://github.com/deyu-deng/Plobi.git
cd Plobi
uv venv --python 3.13 && uv sync --extra dev --extra acp --extra messaging --extra web --extra anthropic
cd apps/desktop && npm install && npm run dev
```

</details>
