## Plobi v0.3.4

[中文](https://github.com/deyu-deng/Plobi/releases/tag/v0.3.4) | [English](https://github.com/deyu-deng/Plobi/releases/download/v0.3.4/Plobi-0.3.4-release-notes.en.md)

v0.3.4 修好抬头那几枚入口的悬浮提示被窗口边缘裁掉的问题，把「必须管理员」的那一小段搬进单独一只侧车，出口规则可以直接写，Agent 的新建与编辑也收进同一个容器。

安装包见本页面下方资产。

### 新增

- **出口规则可直接写** — 出口面板多了一页「规则」：一行一条，域名、`*.子域名`、网段、分类库、地区库、关键词、正则、进程名、来源网段都能写；前缀认不出来时直接点出是哪一段不对。最后那条「默认去向」承担所有没匹配上的流量，删不掉，也挪不到前面。
- **密钥就地测一下** — 凭据卡上多一个「测试」：按下直接给结论，密钥可用（附一句返回样本）、密钥被拒绝、连不上服务，三档分开说。
- **改名之前先讲清** — 外部会话改名时，保存前就写明这次改名会不会同步到对方那款软件里；只改 Plobi 这边的，挂一个「仅本地」。
- **派工卡在哪就写在哪** — 三条说明补上：停在等一句授权、停在等一句答复、前一句还没发完（排队等着，别重发）。

### 改进

- **提权只借那一小段** — 接管流量要建网卡，就得一个管理员进程。以前的路子是把整包设成必须提权，等于每开一次 Plobi 点一次 UAC；现在装的时候注册一条「最高权限、登录触发」的计划任务，跑一只只做三件事的侧车：听管道、认口令、把命令交给引擎与网卡那一套已有实现。主进程保持普通权限，于是它不会因为持有管理员令牌就去改动其他部分。口令落在本人目录、权限收到只有自己；管道名按数据目录区分，两个档案各跑一份也不串门；同一份再启动一次会自己退出。
- **新建与编辑同一个容器** — Agent 表单连壳子一起收成一份，两处只喂数据与文案，不再各写一遍布局。字段顺序统一为名字、中间那一格（新建是品类，编辑是改名清单）、工作目录、外观；提交按钮什么时候可点、错误写在哪、Esc 拦不拦，也只剩一处说法。英文名字段只留一句「小写字母、数字、连字符」，旁边给一个「重新翻译」。
- **探测只剩一处** — 后端环境变量的探测收进一张注册表，旧的那个校验入口改为转发，两边不再各判一次。
- **窗口更新的说法** — 更新接手时那段说明收短，后台迟迟没回传进度就直说还在处理，另给一个「详情」。

### 修复

- **抬头悬浮提示显示不全** — 对话卡右上角三枚入口（档案、待放行、写脑待批）的悬浮提示改走自绘浮层：原生提示由窗口自己画，贴着窗口上边与右边时只剩半截。监控面板的行级说明与标签、档案那颗 pin 上剩下的同类提示一并换掉。
- **Windows 上不再闪出黑窗** — 子进程的窗口抑制收成一个模块。以前只写 `windowsHide` 的地方会出现「父进程不闪、孙进程闪」，而 `detached` 在 Windows 上会把无窗口标志顶掉，黑窗反而必现。

### 安装

下载下方的安装包直接运行——Windows 用 `.exe`（可选择数据目录）或 `.msi`（使用默认位置），macOS 用 `.dmg`，Linux 用 `.deb` / `.rpm` / `.AppImage`。
