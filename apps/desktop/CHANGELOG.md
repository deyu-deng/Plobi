# Plobi Desktop Changelog

## [0.3.0] - 2026-10-31

### 新增功能
- 卡片式主界面：对话与侧栏以独立卡片呈现，视觉更聚焦，可随时切回经典布局。
- 侧边栏全新设计：收起为紧凑图标条，按分类悬浮展开，底部快捷区并入栏内。
- 输入框重新排布：权限三档下拉、上下文容量一目了然。
- 终端页签按 Agent 分家，各 Agent 工作区独立归档、互不串扰。
- 文件页签记住工作区状态：切走自动收起、切回来恢复原位。
- PDF 文档支持直接编辑：选中高亮、按页批注，可写回原文件。
- 定时任务支持停止正在执行的一趟，编辑器可指定错过后如何处理。
- 设置页新增「记忆」管理：逐条查看 Agent 想记住的内容，忘掉需二次确认，杜绝误删。
- 对话中出现「Agent 想记住这条」小卡片，可一键点头或驳回。
- 错误提示升级：按严重度分级，一句话说明 + 一个动作 + 可复制的详情。

### 体验改进
- 主人的消息气泡贴合右侧并高亮，与外部消息形态对齐，对话更易读。
- 「代理（VPN）」设置简化为控制台卡片，高级选项收入「高级」。
- 模型额度状态更清晰：区分是否已登录与当前是否可服务，登录跳转更可靠。
- 额度用尽、网络代理不可达等场景改为人性化文案，不再出现机器术语。
- Agent 能力开关区分「全局关闭」与「本 Agent 关闭」，一目了然。
- 多语言文案去重修正，各语言下额度与错误原因描述更准确。

### 稳定性修复
- 修复本地额度服务健康检查误报：改为强制直连检测并自动恢复，不再弹出误导性错误窗口。
- 修复旧版后端运行时的状态误判，提示更真实。
- 修复渲染层偶发的重复文案与布局错位问题。
