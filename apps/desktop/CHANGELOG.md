# Plobi Desktop Changelog

## [0.3.3] - 2026-11-06

### 新增功能
- 更新面板现在会告诉你有没有**新版的桌面端**，点一下就能装上：下载、退出、装好、自动重启——桌面端与后端一起落到同一个版本号上。
- 「关于」里版本号各归各位：上面那行是你装的桌面端，下面那行是后端（以前两个号串台，0.3.2 的机器会显示 0.1.0）。

### 修复
- 机器忙的时候首启不再被拖成「重装一遍」：检查环境的等待超时不再被当成安装损坏，一个好好的安装不会因为慢被拆掉重来。
- 后端更新在浅 clone 的家上也按得动了（安装器建的那种浅检出以前会把「只是落后」判成「本地有提交」，于是永远拒绝更新）。

## [0.3.1] - 2026-11-05

### 新增功能
- 改一个名字，整条链跟着走：在桌面里给 Agent 改身份名，记忆、信任账、删除台账、外部会话、笔记归属、看板三列与配置都会一起改；动手前先给你看一遍计划，中途出错全部退回，旧名字仍然认得到人。
- 笔记栏升级成工作台：栏宽可拖、多标签页、悬浮预览，wikilink 点得开，笔记能直接编辑。
- 命令行改口：主命令是 `plobi agent`，旧的 `profile` 写法仍然认；界面与报错文案里不再出现「分身」二字。
- 日程详情能加、能勾、能打开附件；周视图按原生日历的样子排。
- 定时任务可以停掉正在跑的一趟，并指定「错过之后怎么办」；导航那一列能挂数量。
- 消息各有各的名：代问的那一条标成「【某某代问】」并换成机器人头像，自己发的那条补上「我」。

### 体验改进
- 设置页五屏与模型那一屏收成「一组一张卡」，浮层与主窗口用同一套几何，图标统一成一把尺。
- 权限档记住上一次：新对话从上一档起步。
- 预览不再挑小文件：大 PDF 直接读字节，Markdown 公式排得出来，Word 文档里的图片与公式正常显示。
- 网络出口收进底栏：控制项集中在一处；代理起来了却没接管到系统流量时当场验、当场撤，退出应用时把系统代理交还。
- 额度卡片更准：每行模型带上自己可调的那几样，订阅额度与登录跳转更可靠。
- 外部会话面板精简；左下角那一组按「整屏在前、面板在后」排。

### 稳定性修复
- 钉钉那一腿取数取错了一头：以前每轮交出的都是最旧的 500 条，新消息进不来。
- Agent 每轮都知道此刻是几点（只用于判断，不落库、不显示）。
- 长驻进程按旧门牌找家的问题修掉；Agent 档案的路径搬进档案区。

## [0.3.0] - 2026-10-31

### 新增功能
- 卡片式主界面：对话与侧栏以独立卡片呈现，视觉更聚焦，可随时切回经典布局。
- 侧边栏全新设计：收起为紧凑图标条，按分类悬浮展开，底部快捷区并入栏内。
- 输入框重新排布：权限三档下拉、上下文容量一目了然。
- 终端页签按 Agent 分家，各 Agent 工作区独立归档、互不串扰。
- 文件页签记住工作区状态：切走自动收起、切回来恢复原位。
- PDF 文档支持直接编辑：选中高亮、按页批注，可写回原文件。
- 定时任务支持停止正在执行的一趟，编辑器可指定错过后如何处理。
- 设置页新增「记忆」管理：逐条查看 Agent 想记住的内容，忘掉需二次确认，杜绝误删。
- 对话中出现「Agent 想记住这条」小卡片，可一键点头或驳回。
- 错误提示升级：按严重度分级，一句话说明 + 一个动作 + 可复制的详情。

### 体验改进
- 主人的消息气泡贴合右侧并高亮，与外部消息形态对齐，对话更易读。
- 「代理（VPN）」设置简化为控制台卡片，高级选项收入「高级」。
- 模型额度状态更清晰：区分是否已登录与当前是否可服务，登录跳转更可靠。
- 额度用尽、网络代理不可达等场景改为人性化文案，不再出现机器术语。
- Agent 能力开关区分「全局关闭」与「本 Agent 关闭」，一目了然。
- 多语言文案去重修正，各语言下额度与错误原因描述更准确。

### 稳定性修复
- 修复本地额度服务健康检查误报：改为强制直连检测并自动恢复，不再弹出误导性错误窗口。
- 修复旧版后端运行时的状态误判，提示更真实。
- 修复渲染层偶发的重复文案与布局错位问题。
