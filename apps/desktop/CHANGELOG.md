# Plobi Desktop Changelog

## [0.3.2] - 2026-11-17

### 新增功能
- 对话里说定一件事即成授权：那句话本身就留作凭据，授权记在账本里，随时可查、可撤回；Agent 起草的草稿不生效，人点头才算。
- 派出去的工作有单据了：当前状态、派给了谁、属于哪个域都能查，点「撤销」即可叫停；定时作业到点后主动汇报。
- 外部工具归到一张真源表（50 家各占一行），新增一家只改一处；48 家带安装引导，未装的那几家第一次接入时给出下载与登录步骤。
- 外部工具可以有多条腿、多套账号：派活时能点名走哪一条腿、用哪一个身份；Gemini CLI、Kilo Code、Cline、kiro、GitHub Copilot、Qoder 中国版的会话可读取与回复。
- 笔记、日记、档案三类补上细动作：列全库、看链接、改属性、勾一条、改一个阶段。
- 信源管理的六把动作：看见、读、翻开关、改频率、落配置、自己触发一轮采集。
- Agent 现在能问、能配：一处能问「这个 Agent 现在能调什么」，名手自带的工具箱与黑名单可在配置面里改。

### 体验改进
- 界面称谓统一：L1 称「指挥」、L2 称「首席」，其余两类角色称「名手」与「客席」，旧称谓不再上屏。
- 对话转录不再每 2.5 秒被拆掉重挂，滚动笔记页不再整树重建 Markdown。
- 加载态统一成品牌小乌龟沿进度条左→右行走；切换界面时加载画面单独显示。
- 档案卡随对话卡容器宽度收窄：窄了就折叠，只留图标。
- 浏览器那一族收成一把 `browser_exec`，十几把点击类工具不再单独注册。
- 换运行时绑定时屏上那份转录跟着走；网关目录 `quota_hub` 改名为 `bezel`，模型名上屏去掉上游前缀。

### 修复
- 随包后端此前是死代码：判定缺失、构建缺包与下载多源回退三处一并修好，装完的后端能被真正拉起。
- 首启标记自愈，更新按安装方式分流；浅克隆装机不再中途失败。
- 关于页永远只印一个版本号；三个平台各一张对味的图标，菜单栏改用 template image。
- 额度那条腿统一叫 WorkBuddy，不再自称 CodeBuddy；它的自更新下载加上断点续传、停滞判定与三轮重试。
- 微信信源没打开时不再报「采集故障」；引擎关着时「系统代理接管」那一格置灰；保存不再抹掉 engine 段。
- 被本地闸拒掉的消息不再静默消失：拒绝带上理由，被拒的那条进队列；发送按 Agent 分桶。

## [0.3.1] - 2026-11-11

### 新增功能
- 额度适配器（magpie）不再跟客户端绑在一起发：它自己查新版、自己下载、自己校验换上，换了起不来会自动退回随包那份。入口在状态栏的额度菜单里，不点它就不下载。
- 「本机已有的账号配置」可以搬进来了：向导和设置里先看一眼本机还有哪些工具留着登录态，再决定搬不搬；搬的是副本，原来的工具不会被登出。
- 进二级 Agent（L2）时接着它自己那条会话：以前每次进去都是新开一条，它上一轮说过什么自己都不记得。
- Models 那一屏可以给单个 Agent 单独指定模型，选择写进它在名册上的那一行，不再全机共用一档。
- 笔记栏右栏补齐五块：反向链接、出链、标签、属性、书签。

### 修复
- 卸载不再把「数据目录在哪一格」一起抹掉：以前卸载会删掉注册表里的路径记忆，重装默认回到 C 盘，D 盘那份库看着就像丢了。
- 数据目录选在移动硬盘或副盘上、那块盘这会儿不在时，启动不再当场崩（以前会拿一格不存在的路径去建目录，直接 ENOENT 掐死），改成退到默认格继续跑，并在启动日志里说清退到了哪一格。
- 桌面端更新不再每次从头拉那 400 MB：已经下完的那份直接复用，下了一半的接着下，收尾按官方尺寸对一遍，对不上就当没下成——半截包不再被递给安装器。
- 名字里带全角罗马数字（如「大学物理（甲）Ⅱ」）的 Agent 按名字找不到人：身份查找只折了名册那一侧，查询串原样不动，于是永远不命中。
- 适配器换版之后不再留旧版本：以前每换一版就在盘上多留一份，一版约 74MB。
- 适配器下载的东西挪出了配置目录：备份或迁移配置时，不会再顺手把一份可执行文件当配置卷走。
- 客户端升级时会正确接管旧适配器：随包那份比已下载的新时不会再被旧的顶住。
- 身份、描述、行级过滤不再指望「每个 Agent 一个家目录」：那套家目录已经退休，读的一律改成名册那一行。

### 体验改进
- 本机的打包也带上离线依赖了：以前「首次启动不用联网」只有 CI 出的包成立，本机打的安装包首启仍要去 PyPI 拉依赖，网络不好就停在转圈。
- 打包前会先把工具链（Git、Node、Python、uv、ffmpeg、ripgrep）凑齐并复用已下好的部分，网络抖动不再让构建白等或反复重下。
- 打包前剔除构建垃圾（下到一半的侧车、pyc 缓存），并新增包体积闸门 `npm run check:payload`：超预算的项会点名。

## [0.3.0] - 2026-11-07

### 新增功能
- 更新面板现在会告诉你有没有**新版的桌面端**，可直接在面板内安装：下载、退出、装好、自动重启——桌面端与后端一起落到同一个版本号上。
- 「关于」里版本号各归各位：上面那行是你装的桌面端，下面那行是后端（以前两个号串台，0.3.2 的机器会显示 0.1.0）。

### 修复
- 机器忙的时候首启不再被拖成「重装一遍」：检查环境的等待超时不再被当成安装损坏，一个好好的安装不会因为慢被拆掉重来。
- 后端更新在浅 clone 的家上也按得动了（安装器建的那种浅检出以前会把「只是落后」判成「本地有提交」，于是永远拒绝更新）。

## [0.3.0] - 2026-10-31

### 新增功能
- 卡片式主界面：对话与侧栏以独立卡片呈现，视觉更聚焦，可随时切回经典布局。
- 侧边栏全新设计：收起为紧凑图标条，按分类悬浮展开，底部快捷区并入栏内。
- 输入框重新排布：权限三档下拉、上下文容量一目了然。
- 终端页签按 Agent 分家，各 Agent 工作区独立归档、互不串扰。
- 文件页签记住工作区状态：切走自动收起、切回来恢复原位。
- PDF 文档支持直接编辑：选中高亮、按页批注，可写回原文件。
- 定时任务支持停止正在执行的一趟，编辑器可指定错过后如何处理。
- 设置页新增「记忆」管理：逐条查看 Agent 想记住的内容，忘掉需二次确认，杜绝误删。
- 对话中出现「Agent 想记住这条」小卡片，可一键点头或驳回。
- 错误提示升级：按严重度分级，一句话说明 + 一个动作 + 可复制的详情。

### 体验改进
- 主人的消息气泡贴合右侧并高亮，与外部消息形态对齐，对话更易读。
- 「代理（VPN）」设置简化为控制台卡片，高级选项收入「高级」。
- 模型额度状态更清晰：区分是否已登录与当前是否可服务，登录跳转更可靠。
- 额度用尽、网络代理不可达等场景改为人性化文案，不再出现机器术语。
- Agent 能力开关区分「全局关闭」与「本 Agent 关闭」，一目了然。
- 多语言文案去重修正，各语言下额度与错误原因描述更准确。

### 稳定性修复
- 修复本地额度服务健康检查误报：改为强制直连检测并自动恢复，不再弹出误导性错误窗口。
- 修复旧版后端运行时的状态误判，提示更真实。
- 修复渲染层偶发的重复文案与布局错位问题。
